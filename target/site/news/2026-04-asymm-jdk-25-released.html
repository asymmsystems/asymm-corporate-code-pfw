Asymm JDK 25.0.2 Available on SDKman

Asymm JDK 25.0.2 is now available for installation via SDKman:

bash 
sdk install java 25.0.2-asymm

Asymm JDK is a server-first OpenJDK distribution with telecom-optimised defaults and enterprise-hardened security. This release is based on OpenJDK 25.

Key features:

  • Telecom-optimised JVM defaults (G1GC tuning, string deduplication, low-latency settings)
  • Enterprise-hardened security configuration (disabled weak TLS protocols, enforced minimum key sizes)
  • Server-first packaging (no desktop modules)

For full details, visit jdk.asymm.systems.
