Asymm Systems

Support

How to reach us about each product, and how fast we answer.

For every product

  • Security reports: security@asymm.systems, acknowledged within 72 hours.
  • Privacy questions and data requests: privacy@asymm.systems; questions within 7 days, data requests within 30 days.

Jira Governance Suite apps

For CascadePlan, LedgerSeal, DefinitionGuard and FourRealities on Jira Cloud.

  • Contact: support@asymm.systems. Please tell us the app, your Atlassian site address, what you did, what you expected and what happened. A screenshot helps.
  • General questions and defects: a first answer within 24 business hours, Monday to Friday.
  • A defect that blocks your production work: within 4 hours.
  • Documentation: the user guides describe each app; the FAQ answers common questions.

Eliya JDK

Eliya is a community distribution. GitHub Issues on the public repository are the support channel; there is no paid support tier and no response time today. Report security problems to the security address above, not in a public issue.

  • Patches: quarterly Critical Patch Updates, as set out in the Eliya lifecycle.
  • Documentation: the Eliya user guide and FAQ.
