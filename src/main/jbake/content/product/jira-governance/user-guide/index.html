User Guide

Jira Governance Suite User Guide

Four Jira Cloud apps and one open verifier. Each app works on its own, and each guide covers setup, every screen, everyday tasks, permissions, data, limits and troubleshooting. Start with the quick start of the app you use, then open its guide.

1. The apps at a glance

2. Quick start for each app

Install the app from the Atlassian Marketplace, or in Jira under Apps > Explore more apps. Steps marked "Jira administrator" need that role; the others need only the usual Jira permissions of the issue or project.

CascadePlan

  1. Open a project and choose CascadePlan Planner.
  2. Open Backlog and drag a work item onto the timeline.
  3. Click a bar, choose Add dependency, set the percent (for example 30) and choose the work item it waits for.
  4. Move the first bar. Read the Jira changes listed before you let go. Ctrl+Z undoes the move.

CascadePlan guide

DefinitionGuard

  1. Open an issue and the Definition of Done panel. A built-in checklist for the issue type is there.
  2. Tick items, add evidence where an item asks for it, or waive an item with a reason.
  3. Jira administrator: add DefinitionGuard DoD Enforcement to every transition into Done.
  4. Project administrator: check Project settings > DefinitionGuard > Gate coverage.

DefinitionGuard guide

LedgerSeal

  1. Open an issue and the Approval Seal panel. Choose Seal this issue, tick the declaration and choose Sign and seal.
  2. Edit the issue: the panel shows what changed since the seal.
  3. Another approver chooses Approve these changes and gives a reason.
  4. Jira administrator: add Require Valid LedgerSeal to the release transition.

LedgerSeal guide

FourRealities

  1. Open Four Realities in the project. The first view builds the project's snapshot.
  2. Use Priority actions and Inspect to find the gaps.
  3. In an issue's Four Realities panel, choose Link decision record.
  4. Administrator: in Evidence reports, choose New evidence report for an audit period.

FourRealities guide

4. Data, privacy and security

  • All four apps run on Atlassian Forge. They store their data in the Forge storage of your site, and FourRealities keeps evidence report files in Forge Object Store. No app sends data outside your Atlassian site.
  • Each app reads and writes Jira as the signed-in user wherever a user acts, so Jira's permissions apply.
  • No app stores email addresses. Account ids are kept only where a rule needs them, reported to Atlassian every week, and removed for closed accounts.
  • After an uninstall, Atlassian keeps the app's storage for 28 days and then deletes it. Issue properties stay on the issues.

Details per app are in the privacy policy and in each guide.
