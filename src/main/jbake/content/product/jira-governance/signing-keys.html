Signing Keys

Signing Keys

LedgerSeal and DefinitionGuard sign some of their records with Ed25519. This page lists the public keys, so that anyone can check a signature.

1. Which records are signed

  • LedgerSeal: the attestation of each seal. It is the issue property ledgerseal-cert, and it is also in the evidence record that you copy from the Approval Seal panel. It holds the snapshot hash, the certificate id and the seal status.
  • DefinitionGuard: the issue property definitionguard-dod, the summary of the issue's Definition of Done checklist.

The algorithm is Ed25519 (RFC 8032). Each signed record names its key id in the field keyId. The public keys below are in SPKI PEM format.

2. What a signature shows

A valid signature shows that the record came from the app that holds the key, and that the record was not changed after it was signed. Asymm Systems holds the private keys. So a signature does not protect against Asymm Systems: someone who holds the private key can sign a new record.

To check a fingerprint, save the PEM text as a file and run:

openssl pkey -pubin -in key.pem -outform DER | sha256sum

5. Checking LedgerSeal evidence

The open verifier checks a LedgerSeal evidence record offline, with no access to Jira or to LedgerSeal. It is in the public repository asymmsystems/ledgerseal-verifier (Apache-2.0), release v1.3.0, and needs Node.js 18 or later.

  1. In the Approval Seal panel, open the seal details and click Show evidence (JSON). Copy the text into a file, for example evidence.json.
  2. Download the verifier release and open a terminal in its folder.
  3. Run node verify-evidence.mjs evidence.json. The verifier reads the key named by the evidence from its keys/ folder. To use a key from this page, save it as a file and give it as the second argument: node verify-evidence.mjs evidence.json key.pem.
  4. Each of the five check lines must start with PASS, and the exit code must be 0. A NOTE line names a redaction entry; it is not a failure.

The Open Verifier guide lists the five checks and what a pass shows.
