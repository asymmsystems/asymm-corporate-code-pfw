Release notes

Brief per-release summary, newest first. Full details of each release (artefact list, SHA256 checksums, GPG signature, Known Limitations with JBS cites) are on the corresponding GitHub Release page.

Authoritative source: github.com/asymmsystems/eliya-jdk/releases.

Eliya 25.0.3: June 2026 (first GA)

Type: first General Availability release. Upstream base: OpenJDK 25.0.3 (2026-04-21).

  • Platforms: Linux x86_64 + Linux aarch64, both shipping in this release.
  • Artefact formats: tarball (.tar.gz), Debian package (.deb), RPM (.rpm), per arch.
  • Signature: Ed25519 detached signature on SHA256SUMS.txt; key fingerprint 076D E547 397A 5D27 EECE E0B3 07A9 0689 B71A 158F (verify-download guide).
  • JRE variant included: ~48 MB; standard Java SE module set plus diagnostic jdk.* modules (JFR, JMX, jcmd attach, PKCS#11) per the JRE curation guide.
  • Eliya-specific: bin/asymm native ELF CLI; -XX:+EliyaProfile=Production activator for production-ready ergonomics (heap dump on OOM, exit-on-OOM, NMT summary, crash log path, container support, diagnostic options unlocked; continuous JFR and unified GC logging by default are Phase 2).
  • Reproducibility: bit-identical builds verified across multiple independent runs on both arches as part of release qualification. See the reproducibility page for what a customer can verify today and how compliance shops requiring independent rebuild verification can engage Asymm directly.
  • Known limitations: four upstream-tracked test failures inherited from OpenJDK 25.0.3 (none are defects in the shipped JDK; full JBS cites in the GitHub Release body).

Installation today: direct tar.gz / .deb / .rpm downloads or via the GitHub Release. SDKMAN! is not yet a supported install path: vendor onboarding is in progress at sdkman/sdkman-db-migrations#783; sdk install java 25.0.3-eliya will work once that PR merges and Eliya's credentials are issued.

CVEs addressed by upstream OpenJDK in the 25.0.3 CPU: see the Oracle April 2026 CPU advisory. Eliya-specific advisories: none.

Next refresh: Eliya 25.0.4 within two weeks of upstream OpenJDK 25.0.4 GA (scheduled 2026-07-21). Quarterly cadence per the lifecycle page.

Eliya 25.0.2: April 2026 (pre-GA build)

Type: pre-GA development build (not a signed release). Upstream base: OpenJDK 25.0.2-ga.

  • Built from openjdk/jdk25u tag jdk-25.0.2-ga.
  • Internal milestone toward the 25.0.3 first GA.
  • Platform: Linux x86_64 only.
  • SDKMAN!: never published; first SDKMAN! registration is queued with 25.0.3 (see PR #783 link in the 25.0.3 entry above).

For production use, install Eliya 25.0.3 (first GA) per the 25.0.3 entry above. 25.0.2 was not signed and is not recommended for production.

Previously (as Asymm JDK)

Earlier development builds were published under the "Asymm JDK" name during the April 2026 rename transition. Eliya 25.0.2 was the first public artefact under the new product name; Eliya 25.0.3 is the first GA. No "Asymm JDK"-era version reached any public distribution channel.
