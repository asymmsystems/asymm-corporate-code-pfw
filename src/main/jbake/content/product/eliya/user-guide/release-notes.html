Eliya 25.0.2 — April 2026

Type: first public release. Upstream base: OpenJDK 25.0.2-ga.

  • Built from openjdk/jdk25u tag jdk-25.0.2-ga.
  • Eliya source patch: -XX:+UseEliyaDefaults flag added (globals.hpp, arguments.cpp).
  • Eliya overlay: hardened java.security; asymm diagnostic CLI.
  • Platform: Linux x64, tar.gz.
  • SDKman: sdk install java 25.0.2-eliya.

CVEs addressed by upstream in this CPU: see the Oracle CPU advisory for April 2026. Eliya-specific advisories: none.

Previously (as Asymm JDK)

Earlier development builds were published under the "Asymm JDK" name during the April 2026 rename transition. Eliya 25.0.2 is the first public release under the new product name; no earlier version reached SDKman.
