User guide

Uninstall

SDKman

sdk uninstall java 25.0.2-eliya Copy

tar.gz archive

Remove the extracted directory. If you registered it with update-alternatives, deregister first:

sudo update-alternatives --remove java /opt/eliya/bin/java Copy
sudo rm -rf /opt/java-25.0.2-eliya Copy

Also unset or edit any shell profile lines exporting JAVA_HOME that pointed at the Eliya install path.

.deb package

sudo apt-get remove eliya-jdk Copy

update-alternatives is deregistered automatically.

.rpm package

sudo rpm -e eliya-jdk Copy

Docker

docker rmi ghcr.io/asymmsystems/eliya:25-lts Copy
